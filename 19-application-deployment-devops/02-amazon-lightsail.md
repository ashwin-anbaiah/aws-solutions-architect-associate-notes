# Amazon Lightsail

## What is Amazon Lightsail?

**Amazon Lightsail** is the simplest way to launch and manage a **Virtual Private Server (VPS)** on AWS. It bundles compute, storage, DNS, and networking into a single **fixed monthly price**.

> "Everything you need to jumpstart a project on AWS — at a predictable price."

## What Lightsail Offers

- **Virtual Private Servers (VPS)** — pre-configured Linux and Windows instances
- **Managed Databases** — MySQL and PostgreSQL with automated backups
- **Container Services** — deploy Docker containers without managing clusters
- **Networking** — static IPs, DNS zones, load balancers, CDN distributions
- **Pre-built application blueprints** — one-click deployments

## Pricing Model

- **Fixed monthly bundles** — no surprise bills
- Includes: vCPUs, RAM, SSD storage, data transfer allowance
- Overages are charged at standard Lightsail rates
- Prices start at ~$3.50/month (as of latest pricing)

## Lightsail vs EC2

| Aspect | Amazon Lightsail | Amazon EC2 |
|---|---|---|
| Target user | Beginners / simple workloads | Advanced / complex workloads |
| Pricing | Fixed monthly bundle | Variable (per second/hour) |
| Configuration | Limited (blueprints) | Highly flexible |
| Scaling | Manual (upgrade plan) | Auto Scaling Groups |
| Networking | Simplified | Full VPC control |
| Use case | Simple websites, dev/test | Enterprise, custom architectures |

## Use Cases

- Simple web applications and websites
- WordPress, Magento, Plesk, Joomla sites
- Development and test environments
- Small business applications
- Personal projects / portfolios

## Key Points / Exam Tips

- Lightsail is for **simple, low-cost** deployments — not for complex enterprise workloads
- **Fixed pricing** is the primary differentiator vs EC2
- Not integrated with the full AWS VPC ecosystem (simplified networking)
- Can **connect to other AWS services** (VPC peering available for advanced use)
- For the exam: if the question mentions "simple VPS", "WordPress", "fixed price", or "jumpstart" — think Lightsail
