# AWS Glue

## What Is AWS Glue?

- **AWS Glue** — fully serverless **data integration and ETL** (Extract, Transform, Load) service.
- Automatically discovers schemas, catalogs metadata, transforms data, and loads it into target systems.
- No infrastructure to manage — fully serverless.

## Core Components

### Glue Data Catalog
- **Central metadata repository** — stores the schema, location, and format of data sources.
- Acts as an index to the location and schema of all your data.
- Used by: **Amazon Athena**, **Amazon EMR**, **AWS Lake Formation**, and Redshift Spectrum.
- Automatically populated by **Glue Crawlers**.

### Glue Crawlers
- Automatically scan data sources (S3, RDS, DynamoDB, JDBC) and infer schemas.
- Create or update **tables** in the Glue Data Catalog.
- Can run on demand or on a schedule.
- The crawler IAM role must have read permissions on the data source.

### Glue Jobs
- Define ETL scripts to transform and move data.
- Supported compute engines: **Apache Spark**, **Python Shell**, **Ray**.
- Jobs run on demand or triggered by events.
- Monitor job performance via dashboards.

### Glue Job Bookmarks
- Remembers which data has already been processed — next job run processes **only new or changed data**.
- Prevents re-processing and duplicate output.
- Can be enabled, disabled, or paused.

### Glue Studio (Visual ETL)
- Web-based visual interface for creating, running, and monitoring ETL jobs.
- Low-code / no-code ETL pipeline builder.

### Glue Streaming ETL
- Processes real-time streaming data from **Kinesis Data Streams** and **Amazon MSK (Kafka)**.
- Targets: S3 or JDBC endpoints.
- Use case: IoT streams, clickstreams, network logs.

### Glue Data Encryption
- In-transit: TLS for connections between sources and targets.
- At rest: KMS encryption for Glue Data Catalog and CloudWatch logs generated by crawlers.
- For S3 targets: attach a Security Configuration to Glue jobs to enable SSE-S3 or SSE-KMS.

## AWS Glue vs Amazon EMR

| Dimension | AWS Glue | Amazon EMR |
|---|---|---|
| Primary purpose | Serverless ETL, schema discovery, data catalog | Big data processing (Spark, Hadoop, Hive, HBase, Presto) |
| Code simplicity | Low-code / visual studio | Requires big data framework expertise |
| Infrastructure | Fully serverless | Requires cluster management |
| Best for | Ad-hoc/small batch ETL, data catalog, incremental loads | Hadoop migration, large-scale distributed processing |
| Frameworks | Spark, Python, Ray | Spark, Hadoop, Hive, HBase, Flink, Presto |

## Key Points / Exam Tips

- **Trigger:** "ETL, serverless, transform data" → **AWS Glue**
- **Trigger:** "automatic schema discovery, metadata catalog" → **Glue Crawler + Glue Data Catalog**
- **Trigger:** "incremental ETL — only process new data each run" → **Glue Job Bookmarks**
- **Trigger:** "visual ETL pipeline builder" → **Glue Studio**
- **Trigger:** "streaming ETL from Kinesis or Kafka" → **Glue Streaming ETL**
- Glue Data Catalog is shared with **Athena**, **Lake Formation**, and **EMR** — central metadata hub
- CSV → Parquet conversion is a common Glue use case — reduces Athena query cost significantly
- Glue is **fully serverless** — no clusters to manage; EMR requires cluster management
